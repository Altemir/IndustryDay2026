실습 계정으로 접속한 뒤
Cowork 시작 화면을 확인하세요.

캡처는 macOS의 실제 Edge 화면입니다. Windows에서도 같은 메뉴를 사용하며, 운영체제와 언어에 따라 화면 배치가 다를 수 있습니다. 붉은 박스와 번호는 조작할 위치를 표시합니다.

1

Edge에서 InPrivate 창 열기

Microsoft Edge를 실행하고, 오른쪽 위 … → 새 InPrivate 창을 선택합니다. 영문 화면에서는 New InPrivate window입니다.

단축키로 바로 열어도 됩니다.

WindowsCtrl + Shift + N
macOS⌘ Command + Shift + N
새 탭이 아니라 새 InPrivate 창입니다.
일반 창에서 새 탭만 여는 것은 InPrivate 모드가 아닙니다. 기존 업무용 창은 닫거나 로그아웃하지 않아도 됩니다.
2

InPrivate 표시 확인 후 접속하기

새 창 오른쪽 위에 InPrivate 표시가 있는지 확인합니다. 검은 배경만으로 판단하지 마세요.

위쪽 주소 표시줄에 다음 주소를 입력하고 Enter를 누릅니다. 보조강사가 별도 접속 주소를 제공했다면 그 주소를 사용합니다.

Copilot 접속 주소 · 새 탭으로 열거나 주소를 복사해 InPrivate 창에 붙여 넣으세요.https://copilot.cloud.microsoft새 탭에서 열기 ↗
링크는 현재 브라우저 창의 새 탭으로 열립니다.
InPrivate 창을 자동으로 만들지는 않습니다. 일반 창에서 이 교안을 보고 있다면 주소를 복사해 InPrivate 창의 위쪽 주소 표시줄에 붙여 넣으세요.
3

배정받은 실습 계정으로 로그인하기

  1. 로그인 화면에 실습 계정의 전자 메일 주소 전체를 입력합니다.
  2. 다음을 선택합니다.
  3. 이어지는 화면에 제공받은 암호를 입력하고 로그인합니다.
계정 선택 화면이 먼저 나오면
개인·회사 계정을 선택하지 말고 다른 계정 사용을 선택합니다. 실습 계정은 이미 준비되어 있으므로 계정을 새로 만들지 않습니다.
4

Cowork 시작 화면 확인하기

로그인한 뒤 서비스 화면의 계정 메뉴에서 배정받은 실습 계정으로 접속했는지 확인합니다. 브라우저 프로필이 아니라 웹사이트에 로그인한 계정을 확인해야 합니다.

Copilot 화면에서 Cowork를 열고, 다음 세 가지를 확인한 뒤 보조강사의 안내를 기다립니다.

접속이 안 될 때

상황대응 방법
InPrivate 메뉴가 없거나 비활성화됨회사 정책으로 제한될 수 있습니다. 설정을 임의로 변경하지 말고 보조강사에게 문의합니다.
개인·회사 계정으로 자동 연결됨다른 계정 사용으로 전환합니다. 이전 InPrivate 세션이 남아 있다면 필요한 작업을 저장하고, 해당 프로필의 모든 InPrivate 창을 닫은 뒤 다시 시작합니다.
암호 오류·추가 인증·접근 차단이 표시됨반복 입력이나 계정 복구를 시도하지 말고, 오류 문구와 실습 계정 번호를 보조강사에게 알려주세요. 암호는 전달하지 않습니다.
로그인은 되지만 Cowork가 보이지 않음로그인 계정을 다시 확인하고 보조강사에게 문의합니다.

실습 종료 시 사용한 InPrivate 창을 모두 닫습니다. 다운로드한 파일은 자동으로 삭제되지 않으므로 별도로 정리합니다.
